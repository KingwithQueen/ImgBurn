# ImgBurn（C 语言复刻工程）

本工程以 C 语言逐步复刻 ImgBurn 2.5.8.0 的功能和操作行为。当前已完成迁移、首轮审计，以及前两阶段的核心错误、镜像元数据和部分解析修正，尚未完成完整复刻，也不应视为已通过真实光盘刻录验收。

## 开发约定

- 主项目名称为 `ImgBurn`，开发环境为 Visual Studio 2026，程序代码使用 C17 和 Windows 原生接口。
- 一句完整代码保持在同一行，过长时再换行；新增或修改的注释使用中文。
- 优先按原版基准补齐功能与行为。改变原版行为的缺陷修复和功能改进在复刻完成后讨论；迁移或构建必需的调整单独记录。
- 功能声明应有证据，分别记录静态审查、离线测试、真实设备操作和人工验收。

## 目录与版本控制

| 路径 | 用途 | 公开追踪 |
| --- | --- | --- |
| `src/` | 程序 C 源码及源码资源 | 是，按后缀白名单 |

`.gitignore` 使用默认忽略、显式放行的规则。测试代码、日志、设备信息、绝对路径、本机隐私资料、参考程序及光盘镜像不进入公开仓库。添加其他类型的程序资源前，应先审查来源和是否适合公开。

本工程不附带原版 ImgBurn 的二进制、解包资源或反编译参考资料。开源许可证尚待项目所有者确定。

## 构建

安装 Visual Studio 2026 的“使用 C++ 的桌面开发”工作负载、MSVC v145 和 Windows SDK，然后打开 `ImgBurn.sln`。虽然工作负载名称包含 C++，本工程所有程序源文件均按 C17 编译。

选择 `Debug` 或 `Release`，平台选择 `Win32` 或 `x64`，生成解决方案。输出为 `out/<平台>/<配置>/ImgBurn.exe`。也可在 VS 开发人员命令提示符中执行：

```bat
msbuild ImgBurn.sln /m /p:Configuration=Release /p:Platform=x64
```

当前入口是既有命令行程序；运行 `ImgBurn.exe --help` 可查看命令。桌面图形界面尚未实现。

## 当前功能状态

程序目前包含 12 个 C 源文件和 11 个头文件，覆盖设备访问、MMC、缓冲区、镜像构建、UDF、音频、镜像解析和部分厂商控制。四种构建配置已验证可以生成，但构建成功不代表功能与原版一致。

| 功能范围 | 当前实现和缺口 |
| --- | --- |
| Read | 缺少从光盘读取完整镜像的应用流程 |
| Build | 已实现 ISO/Joliet 双字节序路径表、目录扇区填充、名称冲突处理及 UDF 1.02/2.50 文件树；2.50 包含元数据分区与副本。支持按配置生成纯 ISO、ISO/Joliet、纯 UDF 或桥接镜像；保留输入一致性和目标文件保护 |
| Write | 已修正输入、写入、收尾及写后校验错误传播；测试写入明确返回尚未实现，介质准备协议与真实刻录未验收 |
| Verify | 已修正空输入、非扇区对齐输入、读取错误及失配结果；真实设备与完整原版流程尚未验收 |
| Discovery | 尚未实现 |
| 桌面界面、设置、任务队列 | 尚未实现 |
| 音频、CUE、MDS、层切换点 | 已修正 WAV 边界、两套 CUE 的文件引用与计数、MDS 字段偏移及短读越界。CUE 当前支持 UTF-8 BINARY/PCM WAVE；MDS 当前支持 1.x 单会话、单文件 DVD。DVD 层切换候选尚未接入实际布局，不再返回推测中点；完整兼容和刻录集成仍待完成 |
| 厂商控制与换盘设备 | 有部分命令封装；参数覆盖及真实硬件行为未验收 |
| 原版命令行接口 | 当前使用子命令，尚不兼容原版 `/MODE` 等接口 |

功能范围以 [ImgBurn 官方说明](https://www.imgburn.com/) 和原版随附的命令行说明为参考。当前仅能认定为部分命令行核心原型，不能认定为完整复刻或可交付的刻录软件。

本机审计记录、原始基线、复现脚本及结果保存在被忽略的 `.local/` 下，不属于公开发布内容。尚未执行真实光盘写入、擦除、设备设置修改或原版逐项人工对照验收。

第二阶段已通过 Win32/x64 离线回归：合计 190 项原生断言及 89 项独立检查。合成样本包含 191 个文件、192 个目录，覆盖多扇区路径表、目录边界、空目录、中文、长名称别名、CRC32 碰撞及重复内容。使用独立读取器提取并核对文件名称、目录集合和 SHA-256，另检查 UDF 标签 CRC、分区地址、主备描述序列及元数据副本。x64 解析回归另经 AddressSanitizer 检查；两个架构的 MSVC 静态分析未报告警告。此结果属于离线验证，不等同于原版逐项对照、完整格式认证或真实设备验收。

当前明确限制：单文件最大为 4 GiB−1；源路径及镜像相对路径受 `MAX_PATH` 限制，名称分量最多 127 个 UTF-16 代码单元，暂不支持代理项字符。ISO 和 Joliet 分别使用有界唯一别名，UDF 保留受支持的原名。引导镜像、DVD-Video/Blu-ray 合规布局、其他 UDF 修订号、多会话和分卷 MDS 尚未接入；相关配置明确失败，避免生成不完整结果。

后续继续补齐大文件、多格式和视频布局，再开展 GUI、Read、Discovery 等功能。原版缺陷修复与额外改进仍在复刻完成后讨论。
